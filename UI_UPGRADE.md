# EcoVision AI — UI Upgrade Reference

This version uses the supplied friend-project screenshots as UX inspiration rather than copying the product itself.

## Design direction
- Light sage/cream SaaS interface
- Large editorial headings and generous whitespace
- Rounded white cards with subtle borders
- Green sustainability accent
- Product-style dashboard greeting
- Weekly activity strip
- KPI cards and quick actions
- Light role-aware sidebar
- Floating Prakriti AI assistant

## Navigation behavior
- Public landing page: no sidebar.
- Authentication: Google or Email.
- After login: custom role-aware sidebar appears.
- Streamlit's generated multipage navigation is hidden.
- Citizen, Officer and Admin get separate navigation sets.

## Preserved functionality
Existing EcoVision waste reporting, AI classification, complaint tracking, recycling tools, analytics, reports and Prakriti AI logic are retained. The UI layer is redesigned around them.
